# Task 5: Decision Trees and Random Forests

## 📌 Objective

The objective of this task is to learn and implement tree-based machine learning models for classification.

In this project, Decision Tree and Random Forest models are trained using the Heart Disease dataset.

## 📊 Dataset

The Heart Disease dataset (`heart.csv`) is used for this project to predict the presence of heart disease.

## 🛠️ Tools and Libraries

* Python
* Google Colab
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

## 🌳 Tasks Performed

* Loaded and explored the dataset
* Checked for missing values
* Split the dataset into training and testing sets
* Trained a Decision Tree Classifier
* Visualized the Decision Tree
* Analyzed overfitting using different tree depths
* Trained a Random Forest Classifier
* Compared the accuracy of both models
* Analyzed feature importance
* Performed 5-fold cross-validation

## 📈 Models Used

### Decision Tree Classifier

A Decision Tree makes predictions by splitting data based on different features. It is easy to understand and visualize but can overfit the training data.

### Random Forest Classifier

Random Forest combines multiple Decision Trees to make predictions. It generally provides more stable performance and helps reduce overfitting.

## 🔍 Key Learning Outcomes

* Understanding Decision Trees
* Understanding Random Forests
* Overfitting and controlling tree depth
* Ensemble learning and bagging
* Feature importance
* Cross-validation
* Model evaluation and comparison

The Decision Tree model was easy to understand and visualize. However, deeper trees can lead to overfitting.
